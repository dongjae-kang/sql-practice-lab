# SQL Practice Lab

Practice PostgreSQL queries on the Iowa Liquor Sales class database in the browser. PostgreSQL runs inside each browser with PGlite, so there is no shared server and nothing to install.

Live site: https://dongjae-kang.github.io/sql-practice-lab/

- Layout follows the pgAdmin 4 Query Tool: Object Explorer, F5 to run, Data Output and Messages tabs.
- Tables: counties, products, stores, sales (3,049,913 rows), with the same columns and types as the course database.
- Data: Iowa Alcoholic Beverages Division, published on data.iowa.gov, as distributed in SIPA IA 6652.

Built by Dongjae Kang.
